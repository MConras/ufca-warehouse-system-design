# User Stories — Sistema de Almoxarifado

## 1. Contexto

O sistema tem como objetivo auxiliar no gerenciamento de materiais de um almoxarifado, permitindo controlar o estoque, as solicitações de materiais e o acesso dos usuários.

### Tipos de usuários

- **Usuário:** funcionário que solicita materiais.
- **Gestor do Almoxarifado:** responsável pelo controle do estoque e das solicitações.
- **Administrador do Sistema:** responsável pelo gerenciamento de usuários e permissões.

## 3. Resumo das Prioridades

### Alta
- Consultar disponibilidade de materiais.
- Solicitar materiais.
- Receber notificações sobre solicitações.
- Cadastrar novos materiais.
- Registrar entrada e saída de materiais.
- Visualizar materiais com estoque baixo.

### Média
- Visualizar histórico de solicitações.
- Cancelar solicitações.
- Gerenciar permissões de usuários.

### Baixa
- Gerar relatórios de movimentação do estoque.
