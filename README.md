## 📌 Sobre o Projeto
O projeto visa solucionar gargalos operacionais no almoxarifado universitário, substituindo o controle manual por uma especificação centralizada e digital. O foco abrange o fluxo de consulta de disponibilidade, solicitações de empréstimo, notificações de prazos, controle de devoluções com estado de conservação e relatórios operacionais.
